# ukrainians.civ.fm — Ukrainians

A record of everyone who made Ukraine: 110,921 lives drawn from Wikidata,
arranged by time, by origin, by field, and by state honour.

| Page | What it is |
|---|---|
| `index.html` | Front door — how it works, the four sections, category previews |
| `timeline.html` | 4,922 documented figures across twenty-five centuries |
| `roots.html` | 4,009 people born since 1900, plus the worldwide diaspora |
| `heroes.html` | All 898 recorded Heroes of Ukraine |
| `method.html` | Inclusion rules, known biases, corrections form |

Static, no build step at serve time. Generated from `~/Growth/ukraine-pantheon`
by `python3 build_site.py`; deploy with `./deploy.sh` from that project.

Data: [Wikidata](https://www.wikidata.org) (CC0). An independent project,
not an official register.
